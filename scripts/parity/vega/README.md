# Fire TV (Vega OS) parity run

`run.sh <out-dir> [screens|dpad]` reproduces the full run on the Vega virtual device against the static parity server:
15 screens in dark and light and the 12 non-player D-pad checks.
See the header of `run.sh` for the setup it expects and `docs/parity/DEVICES.md` for the device notes.

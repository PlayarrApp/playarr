Static instances of the shared Nunito Sans variable font (docs/parity/fonts/NunitoSans-wght-web.ttf) at the weights the
web phone layout uses (see scripts/parity/sailfish/build-fonts.sh for the list). Qt 5.6 only draws a variable font's default
weight, so each weight is a separate file. Regenerate all with `scripts/parity/sailfish/build-fonts.sh`. Licence: OFL-NunitoSans.txt.
